# BhaivaTech Homes preview

Static HTML, CSS, and JavaScript preview for a Bengaluru property discovery service.

## Run locally

```bash
python3 -m http.server 8080
```

Open `http://127.0.0.1:8080/index.html`.

## Included pages

- `index.html`: main landing page with SEO content, Rent and Buy paths, guides, FAQ, and lead form.
- `properties/index.html`: filterable catalogue preview.
- `property-preview.html`: individual listing page template.
- `about.html`: service positioning and trust boundaries.
- `how-we-verify.html`: checking policy content.
- `renters-guide.html` and `buyers-guide.html`: practical Bengaluru guides.
- `contact.html`: lead form and WhatsApp path.

## Before launch

Replace preview listings, images, canonical URLs, sitemap URLs, form handling, contact details, legal copy, and noindex directives with client-approved production values. Confirm the property subdomain and connect Search Console for the parent domain and subdomain.
